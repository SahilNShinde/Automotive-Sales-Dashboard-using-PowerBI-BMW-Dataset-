# 🚗 BMW Global Sales & Performance Analytics Dashboard

An interactive, multi-page Power BI business intelligence dashboard designed to analyze BMW sales performance, revenue generation, and market trends across major vehicle series, fuel types, and global regions.

---

## 📊 Project Overview
This project provides high-level executive KPIs and granular segment drill-downs across four core product categories:
* **M Series** (High-performance luxury cars)
* **X Series** (Sporty, luxury SUVs)
* **Model Series** (Executive luxury sedans)
* **I Series** (Sustainable electric & hybrid vehicles)

## 🔑 Key Features & Insights
* **Multi-Page Navigation:** Custom header navigation linking all vehicle segments seamlessly with persistent filtering.
* **Core KPI Tracking:** Dynamic calculation of **Total Sales Volume**, **Total Revenue ($M / $B)**, and **Average Price ($K)**.
* **Fuel Type Distribution:** Donut chart breakdown analyzing market share between Petrol, Diesel, Hybrid, and Electric powertrains.
* **Geographic Analysis:** Regional distribution across North America, Europe, Asia, Middle East, South America, and Africa.
* **Interactive Slicers:** Deep cross-filtering by transmission type (Automatic vs. Manual) and model release year ranges (2010–2024).

---

## 🛠️ Tech Stack & Skills
* **Business Intelligence Tool:** Microsoft Power BI Desktop
* **Data Modeling & DAX:** Custom measures for aggregations, dynamic titles, and ratio analysis
* **Data Transformation:** Power Query (ETL, schema cleanup, data normalization)
* **Visual Design:** Custom UI cards, dark-theme layout, and synchronized cross-visual interactions
